# 作业与章节测验

1. 用户要求作答时使用 `browser_site_chaoxing__auto_answer`。每批默认四题、最多四题；后续批次保持 `assignment_id` 并传回执的 `next_offset`。题号范围使用 `question_range={start,end}`，重复或缺失的显示题号拒绝自动填写。
2. 答案依次来自页面已公布解析、本地精确题库和模型。本仓库没有远程题库服务，不应声称已查询服务器。
3. 服务器答案按题型、完整题干和选项内容匹配，选项重排重新映射；同题重复、矛盾或截断数据不自动采用。本地题库多条命中须一致。模型只收到当前批次中尚无答案的题目，一次请求最多四题，不发送整份作业。
4. 只读用 `browser_site_chaoxing__read_questions`，默认四题、最多八题。实填选项与普通填空值同步到软件题目面板。`question_id` 绑定文档、题序和题干选项指纹；填写前和填写后重新核对。单选、多选、判断使用当前选项字母 `choices`，填空用顺序一致的 `blanks`。
5. `browser_site_chaoxing__answer_questions` 不覆盖不同的已有答案。`verified` 仅表示网页实填一致，不表示知识正确；不保存或交卷。含图、公式、混淆字体、材料题、过长内容和未知题型返回 `supported=false`，由 Agent 进一步核对。

本仓库不注册后台解析上传任务。通用宿主提供服务能力，不代表本仓库已配置相应服务；字体解码仍未迁入编译包，不得猜测混淆文字或自动填答。
