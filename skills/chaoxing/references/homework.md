# 作业与章节测验

1. 用 `browser_site_chaoxing__read_questions` 读取当前题目，每批默认四题、最多八题。`offset` 是当前文档中的偏移，保持用户要求的范围。
2. 题目标识绑定当前文档、题序和题干选项指纹。填答前重新读题；换题、重载或选项变化时拒绝旧标识。
3. 单选、多选、判断使用当前选项字母 `choices`，填空使用顺序一致的 `blanks`。`question_id` 使用本批返回值。
4. 用通用题库工具查找精确答案；当前环境没有相应工具时明确说明。页面已公布的解析来自 `reviewAnswer`。两者不能确认时由模型结合题干推理，保留不确定性。
5. `browser_site_chaoxing__answer_questions` 保留不同的已有作答，填后回读。`verified` 只表示网页实填一致，不表示知识正确。没有自动保存、交卷或上传答案。

含图、公式、混淆字体、材料题和未识别题型返回 `supported=false`，由 Agent 使用当前通用浏览器能力进一步核对。宿主未开放题库 HTTP、网络答案监听或字体解码接口，当前编译包不会冒充已实现这些能力；也不会回退到软件内的平台脚本。填空仅返回是否有作答，普通内容可用相等性核对，凭据字段拒绝比较。
